# About

This is the starter content of the SMGen **journal** theme, one of the base
themes in the [smgen-extras](https://seanmorris.github.io/smgen-extras/themes.html#theme-journal)
collection. The four entries explain the theme as they go; delete them when
you have entries of your own.

The front page, the topic pages and the archive in the margin are all built
at compile time from the files under `pages/posts/` and `pages/topics/`, and
SMGen core writes the RSS feed from the entries that carry `feeds: [posts]`.
Set the feed's title and description under `RSS_FEEDS` in `.smgen.yaml`.

For a finished notebook built on this theme, see the Commonplace example in
[smgen-extras](https://seanmorris.github.io/smgen-extras/examples/commonplace/).
