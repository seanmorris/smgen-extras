Topics are only files. This entry belongs to a second one, Projects, which
exists because `pages/topics/projects.md` exists. A topic page lists the
entries that name it, so a running log of one piece of work reads in order
from its own page while still appearing in the main stream.

> Write down what you decided and why. The what is in the files; the why is
> gone by Friday.
