Photographs live in `static/images/`. Name the file in the frontmatter as
`image: /images/second-entry.webp`, add `imageAlt:` for the caption, and
drop smaller renditions named `second-entry-1200.webp` and
`second-entry-800.webp` beside it for the browser to choose from. A
`gallery:` list adds further plates below the text.
