# About

This is the starter content of the SMGen **portfolio** theme, one of the base
themes in the [smgen-extras](https://seanmorris.github.io/smgen-extras/themes.html#theme-portfolio)
collection. Say who you are here, in a few short paragraphs, and put a
photograph of the place you work in with a Markdown image; it is set as a
plate with its caption.

## How the site works

Each piece of work is one Markdown file under `pages/work/`. The front page
and the Work page read every file's frontmatter at build time and number the
entries, newest first. An entry with an `image:` gets a plate; one without
is listed by its title, kind and year, so it can be published before it is
photographed.

For a finished site built on this theme, see the Halden Bindery example in
[smgen-extras](https://seanmorris.github.io/smgen-extras/examples/halden-bindery/).
