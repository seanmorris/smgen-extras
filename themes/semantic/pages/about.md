# About

Plain is a fictional site. It exists to demonstrate the SMGen semantic theme,
one of the base themes in the [smgen-extras](https://seanmorris.github.io/smgen-extras/)
collection, and its only content is about itself.

The theme is a single PHP template, a stylesheet you can read in one glance,
and this handful of Markdown pages. Start your own copy with:

```bash
npm create smgen-site@latest my-site -- --theme semantic
```

Then build it with [SMGen](https://seanmorris.github.io/smgen/):

```bash
cd my-site
smgen build
```
