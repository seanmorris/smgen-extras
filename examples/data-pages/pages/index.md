# Two CSV files, one site

The [customer directory](customers/index.html) and
[organization directory](organizations/index.html) contain 24 records each.
SMGen builds every detail page and both indexes from the two source files.

Each dataset maps its original headings to short template variables. Change a
CSV row, run SMGen, and its detail page and directory entry update together.

The files are excerpts from Datablist's
<a href="https://www.datablist.com/learn/csv/download-sample-csv-files" target="_blank" rel="noopener noreferrer">synthetic sample CSV files</a>.

<a href="https://seanmorris.github.io/smgen-plugins/data-pages.html" target="_blank" rel="noopener noreferrer">Read the smgen-data-pages guide</a>
or <a href="https://github.com/seanmorris/smgen-plugins/tree/main/examples/data-pages" target="_blank" rel="noopener noreferrer">inspect this example's source</a>.
