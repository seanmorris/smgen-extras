# A field guide from CSV

The [published field notes](notes/index.html) come from one spreadsheet and two
PHP templates. The `Published` column excludes the draft row before any page is
rendered.

Change `data/field-notes.csv`, run SMGen, and the catalog and detail pages
update together.

[Read the smgen-data-pages guide](https://seanmorris.github.io/smgen-plugins/data-pages.html)
or [inspect this example's source](https://github.com/seanmorris/smgen-plugins/tree/main/examples/data-pages).
